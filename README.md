Официальная интернет-витрина и каталог товаров для молодых мам в г. Шемонаиха (Восточно-Казахстанская область, Казахстан).

## ✨ Возможности витрины
* **Интерактивный выбор размера:** Мгновенный пересчет веса малыша и количества штук в пачке (M, L, XL, XXL, XXXL).
* **Фильтрация по категориям и брендам:** «Мама знает», «Baybee», «Baby Shark», «Softcare», эко-химия для стирки и уборки.
* **1-клик заказ в WhatsApp:** Автоматическое формирование списка покупок, выбранных размеров, адреса доставки и итоговой суммы в ₸.
* **100% Мобильная адаптивность:** Оптимизировано для открытия из био Instagram и WhatsApp на смартфонах.

---

## 🛠 Технический стек
* **Frontend:** Clean HTML5, Vanilla CSS3 (пастельная дизайн-система, Glassmorphism, микро-анимации), Vanilla JS.
* **База данных:** JSON-каталог `data/products.json`.
* **Быстродействие:** 100/100 Google PageSpeed, нулевая задержка загрузки на 3G/4G сетях.
* **Хостинг:** GitHub Pages (бесплатный, статический).
