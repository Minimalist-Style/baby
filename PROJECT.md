## 🎯 2. Бизнес-задача и Архитектура

### Главная цель:
Создать стильный, легкий, минималистичный веб-сайт (каталог-лендинг), который:
1. Вызывает мгновенное доверие мам нежным визуалом (уровень ведущих брендов вроде *«Мама Знает»*).
2. Позволяет выбрать бренд, нужный размер (`NB`, `S/1`, `M/2`, `L/3`, `XL/4`, `XXL/5`) и количество пачек.
3. Оформляет заказ в **1 клик в WhatsApp** с автоматическим формированием корзины, итоговой суммы и адреса доставки.

### Технический стек (Clean & Fast):
* **Структура:** Модульный одностраничный веб-каталог (HTML5 + Vanilla CSS / Glassmorphism + чистый JS без тяжелых фреймворков для мгновенной загрузки даже на слабом 3G/4G).
* **Интеграция:** WhatsApp API (`https://wa.me/77779805639?text=...`) с динамической сборкой текста заказа.
* **Каталог:** JSON-структура товаров с размерами, количеством штук в упаковке, весовыми категориями и ценами в тенге (`₸`).

## 🎨 4. Дизайн-Код и Айдентика

* **Основная концепция:** Забота, нежность, чистота, легкость.
* **Символ:** Милая маленькая пчелка (Baby Bee), бережно обнимающая мягкое облако-подгузник.
* **Цветовая палитра:**
  * `Primary Accent`: Теплый медовый / пастельно-желтый (`#FFC837` / `#F8B84E`)
  * `Soft Background`: Нежный молочно-кремовый (`#FFFDF9`)
  * `Secondary / Care`: Мягкий небесно-голубой (`#70C8F4`) и чистый белый (`#FFFFFF`)
  * `Text Ink`: Глубокий мягкий темно-серый (`#2C3539`, не ядовито-черный)
